云端同步（GitHub Gist · 永久免费）

把备份同步到 GitHub 云端，换电脑、换浏览器也能恢复同一份数据。
只需一个免费 GitHub 账号：GitHub → Settings → Developer settings → Personal access tokens → 生成一个 token（勾选 gist 权限即可），把 token 粘贴到下面。

Token 和 Gist ID 仅保存在本机浏览器 localStorage，不会上传到任何第三方。GitHub Gist 是 GitHub 官方提供的免费私密代码片段空间，数据只有持 token 的人能读写。
